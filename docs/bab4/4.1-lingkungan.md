# 4.1 Lingkungan Implementasi

Implementasi Sistem Informasi Laundry Koin menggunakan bahasa pemrograman Python versi 3.10.6 dengan lingkungan virtual `.venv` yang dibuat di folder proyek. Pemilihan Python 3.10 didasarkan pada batas minimum yang ditetapkan pada `aturan-proyek.md`, yaitu Python 3.10 atau lebih baru; seluruh kode ditulis memakai fitur standar yang tersedia pada versi tersebut sehingga tidak bergantung pada fitur eksklusif versi terbaru. Framework backend yang dipakai adalah Flask 3.1.3, yang menyediakan mekanisme routing, templat Jinja2, dan sesi berbasis cookie bertanda tangan. Database memakai SQLite melalui modul pustaka standar `sqlite3`; tidak ada server database terpisah yang diperlukan, sehingga aplikasi cocok untuk lingkungan usaha kecil seperti laundry koin. Untuk kebutuhan produksi, server WSGI Waitress 3.0.2 dipasang dan dicatat pada `requirements.txt`. Dependensi pengujian pada `requirements-dev.txt` memuat pytest 9.1.1, yang dipakai untuk uji otomatis sejak Jobsheet 13.

Tabel berikut merangkum versi perangkat yang digunakan. Semua angka diambil dari hasil `python --version` dan `pip freeze` pada virtual environment, bukan dari perkiraan.

Asisten AI berperan sebagai alat bantu penulisan draf kode, dokumentasi, dan uji, bukan sebagai pengambil keputusan. Setiap keluaran AI ditinjau baris demi baris sebelum di-commit: validasi dipindahkan ke lapisan service, kunci rahasia diambil dari variabel lingkungan, dan perintah README hanya ditulis setelah perintah tersebut dijalankan sendiri. Cara kerja ini dicatat secara rinci pada `jurnal/nabila.md` dengan kolom Keputusan Terima, Ubah, atau Tolak. Seluruh perubahan dapat ditelusuri kembali melalui riwayat Git pada branch fitur yang telah digabung.

Pernyataan penggunaan AI: alat yang dipakai adalah asisten AI percakapan untuk merapikan bahasa draf, mengusulkan potongan kode, dan menyusun kerangka uji serta salindia. Tujuannya mempercepat penulisan, bukan menggantikan pemeriksaan. Keluaran AI selalu dibandingkan dengan bukti lokal (skema, hasil uji, dan keluaran perintah), lalu diterima, diubah, atau ditolak; rinciannya terdapat pada 25 entri `jurnal/nabila.md`, termasuk tiga entri bertanda `[Debug]`.
