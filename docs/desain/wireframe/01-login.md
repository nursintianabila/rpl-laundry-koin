\# WIREFRAME 01 — LOGIN



\## Sistem Informasi Laundry Koin



\### 1. Tujuan Halaman



Halaman Login digunakan oleh Pemilik dan Admin/Operator untuk masuk ke dalam sistem menggunakan akun yang telah terdaftar.



\### 2. Sketsa Wireframe



```text

+--------------------------------------------------+

|                                                  |

|              SISTEM INFORMASI                   |

|                  LAUNDRY KOIN                    |

|                                                  |

|          Silakan masuk ke akun Anda              |

|                                                  |

|          Username / Email                       |

|          +--------------------------------+      |

|          |                                |      |

|          +--------------------------------+      |

|                                                  |

|          Password                                |

|          +--------------------------------+      |

|          |                                |      |

|          +--------------------------------+      |

|                                                  |

|          +--------------------------------+      |

|          |            MASUK               |      |

|          +--------------------------------+      |

|                                                  |

|                                                  |

+--------------------------------------------------+

```



\### 3. Komponen Halaman



| No. | Komponen | Fungsi |

|---|---|---|

| 1 | Nama Sistem | Menampilkan identitas aplikasi |

| 2 | Input Username/Email | Tempat memasukkan identitas akun |

| 3 | Input Password | Tempat memasukkan kata sandi |

| 4 | Tombol Masuk | Memproses autentikasi pengguna |

| 5 | Pesan Kesalahan | Menampilkan informasi apabila login gagal |



\### 4. Anotasi



1\. Form login dibuat sederhana agar mudah dipahami pengguna.

2\. Input username/email dan password wajib diisi.

3\. Password tidak ditampilkan dalam bentuk teks biasa.

4\. Pesan kesalahan ditampilkan apabila data login tidak sesuai.

5\. Setelah berhasil login, pengguna diarahkan berdasarkan perannya.



\### 5. Prinsip Desain



\- Konsistensi: menggunakan gaya komponen yang sama dengan halaman lain.

\- Kesederhanaan: hanya menampilkan elemen yang diperlukan untuk login.

\- Kejelasan: setiap kolom memiliki label yang mudah dipahami.

\- Pencegahan kesalahan: memberikan validasi untuk input yang kosong.
