\# WIREFRAME 07 — DATA PELANGGAN



\## Sistem Informasi Laundry Koin



\### 1. Tujuan Halaman



Halaman Data Pelanggan digunakan oleh Admin/Operator untuk melihat dan mengelola informasi pelanggan yang terdaftar dalam sistem.

\### 3. Komponen Halaman



| No. | Komponen | Fungsi |

|---|---|---|

| 1 | Header | Menampilkan identitas sistem dan pengguna |

| 2 | Navigasi | Menampilkan menu sesuai hak akses |

| 3 | Judul Halaman | Menunjukkan halaman Data Pelanggan |

| 4 | Kolom Pencarian | Membantu mencari data pelanggan |

| 5 | Tombol Tambah Pelanggan | Membuka form penambahan pelanggan |

| 6 | Tabel Pelanggan | Menampilkan daftar pelanggan |

| 7 | ID Pelanggan | Menampilkan identitas pelanggan |

| 8 | Nama Pelanggan | Menampilkan nama pelanggan |

| 9 | Kontak | Menampilkan informasi kontak jika tersedia |

| 10 | Aksi | Membuka rincian atau pengelolaan data pelanggan |



\### 4. Anotasi



1\. Data pelanggan ditampilkan dalam bentuk tabel.

2\. Admin/Operator dapat mencari pelanggan berdasarkan informasi yang tersedia.

3\. Admin/Operator dapat menambahkan data pelanggan baru.

4\. Informasi pelanggan digunakan sebagai data pendukung dalam pencatatan transaksi.

5\. Data pelanggan yang dipilih dapat digunakan pada Form Transaksi.



\### 5. Prinsip Desain



\- Keterbacaan: data disusun dalam tabel agar mudah dibaca.

\- Efisiensi: pencarian membantu menemukan data pelanggan.

\- Konsistensi: bentuk tabel mengikuti halaman daftar transaksi.

\- Pencegahan kesalahan: data pelanggan perlu diperiksa sebelum disimpan.



\### 6. Catatan



Rincian atribut pelanggan masih mengikuti kamus data awal dan perlu disesuaikan setelah struktur data dikonfirmasi. Contoh data pada sketsa bukan data pelanggan sebenarnya.
